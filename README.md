# Nan Sheng personal website

Compact Stanford/jemdoc-style static website for `nansheng.me`.

This package contains:
- `index.html`
- `research.html`
- `papers.html`
- `teaching.html`
- `jemdoc.css`
- `cv.pdf`
- `img/`

Deploy with the local helper script:

```bash
./deploy_nansheng_me_only.sh ~/Downloads/nansheng_stanford_site_simple_v34.zip
```

The Stanford page can remain a permanent redirect to `https://nansheng.me/`.
